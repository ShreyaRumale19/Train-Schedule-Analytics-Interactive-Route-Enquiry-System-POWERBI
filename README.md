# Train Schedule Data Analysis and Interactive Route Enquiry System

## Project Overview

This project focuses on analyzing train schedule data using Python and developing an interactive Power BI dashboard for train, station, route, and journey analysis.

## Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Power BI

## Project Progress

### Level 1 — Data Exploration & Basic Review

- Dataset overview
- Dataset structure
- Total records and attributes
- Train information
- Starting and ending stations
- Number of station records per train
- Maximum and minimum station records

**Status: Completed**

### Level 2 — Data Processing & Feature Engineering

- Arrival and departure time standardization — Completed
- Journey duration calculation — In Progress
- Route classification — Pending
- Station-wise train frequency — Pending

**Status: In Progress**

## Project Status

The project is currently under development. Each level is maintained separately for organized internship submission and project tracking.
